# KIET Landing Page

A front-end landing page project for KIET, built with HTML, CSS, and JavaScript.

## Live Demo

[View the deployed website](https://kiet-landing-page.netlify.app/)

## Repository

[GitHub Repository](https://github.com/ZahimFarooqi0/KIET-Landing-Page)

## Built With

- **HTML5** — page structure and content
- **CSS3** — styling and layout
- **JavaScript** — client-side interactions

## Project Structure

```text
KIET-Landing-Page/
├── index.html   # Main webpage
├── style.css    # Stylesheet
└── script.js    # JavaScript functionality
```

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ZahimFarooqi0/KIET-Landing-Page.git
   ```

2. Open the project folder:

   ```bash
   cd KIET-Landing-Page
   ```

3. Open `index.html` in your browser.

   You can also use the Live Server extension in Visual Studio Code for local development.
